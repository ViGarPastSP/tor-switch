Tor Switch Options

Version 1.0 uses fixed defaults. Configurable host, port, and scheme will be available in a future release.

Current defaults

Host
127.0.0.1
Port
9050
Scheme
SOCKS5

About

Tor Switch only configures the browser proxy settings. It does not contain Tor and does not provide anonymity by itself. You must run a compatible local SOCKS5 service (for example the official Tor client) that listens on the address above.

Settings changes are not yet editable in this version. The extension remains fully functional with the defaults.
